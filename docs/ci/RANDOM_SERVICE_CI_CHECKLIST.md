# Public Random Service CI Checklist

Status: P1-21 engineering checklist.

## Default provider lanes

Run on Linux, Windows, and Apple reviewed provider branches:

1. Configure with OS entropy enabled and both internal test hooks disabled.
2. Build with strict warnings.
3. Run `ano_crypto_random_service_tests` and `ano_crypto_random_lifecycle_stress_tests`.
4. Confirm context-size, init, generate, reseed, and uninit behavior.
5. Confirm unsupported prediction-resistance requests and oversized requests fail and clear valid output buffers.
6. Confirm explicit-entropy DRBG contexts and source-backed random contexts cannot be exchanged across APIs.
7. Confirm service availability requires both the reviewed provider branch and process-marker support.
8. On POSIX, confirm inherited source-backed state requires reseed in the child.
9. Capture `ano_crypto_random_platform_review` as status-only hosted evidence.
10. Run installed-package and PoC smoke flows.
11. Run both random policy targets.

## Provider-disabled lane

Configure with:

```text
ANO_CRYPTO_ENABLE_OS_ENTROPY_PROVIDER=OFF
ANO_CRYPTO_ENABLE_ENTROPY_TEST_HOOKS=OFF
ANO_CRYPTO_ENABLE_RANDOM_TEST_HOOKS=OFF
```

Confirm the random service is unavailable, size/init return `ANO_CRYPTO_ERR_NOT_IMPLEMENTED`, caller storage is cleared where documented, and unrelated services continue to pass.

## Dedicated hardening lane

Configure tests with OS entropy disabled and both internal hooks enabled. Confirm:

- deterministic init/generate/reseed behavior;
- complete and partial provider failures clear affected storage/output;
- failed reseed leaves the reseed-required gate intact;
- successful reseed restores generation;
- the last allowed reseed-counter value succeeds and the next generate returns `ANO_CRYPTO_ERR_DRBG_RESEED_REQUIRED`;
- a maximum counter does not wrap;
- no deterministic provider bytes or generated bytes are printed or retained.

## Clean Release and PoC checks

- Tests and both test hooks are OFF.
- Internal symbol hiding is ON.
- Installed headers contain no internal entropy, process-guard, reseed-counter, or test-hook token.
- The clean shared library exactly matches `abi/ANOCRYPTO_C_0_EXPORTED_SYMBOLS.txt` (61 public symbols).
- The PoC package includes lifecycle and clean-export review records.
- Examples print statuses and byte counts only.

## Portability checks

- Unsupported process-marker platforms fail closed rather than silently disabling duplication detection.
- Known VM snapshot/restore or clone events require inherited state to be discarded and each instance independently reinitialized.
- Suspend/resume behavior remains an integration policy; no automatic detection claim is made.
- Hosted Linux/macOS/Windows review artifacts contain provider name, availability, process-marker support, statuses, and `generated_bytes_logged=no` only.

## Evidence checks

- `RANDOM_SERVICE_CHECK.txt` passes.
- `RANDOM_LIFECYCLE_HARDENING_CHECK.txt` passes.
- `EXPORTED_SYMBOL_BASELINE_CHECK.txt` reports 53 expected and actual public symbols.
- Lifecycle review notes document VM/process limitations.
- Evidence contains no provider output, entropy, nonce seed material, DRBG state, or generated random bytes.
