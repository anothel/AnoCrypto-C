## Rating meanings

- `READY_TO_PRESENT`: current position, evidence anchor and open decision are clear.
- `READY_TO_PRESENT_WITH_BLOCKER`: answer is clear but a material implementation or evidence blocker must be stated.
- `READY_TO_ASK_NOT_READY_TO_DECIDE`: the project can ask the question but cannot select the answer internally.
- `READY_TO_PRESENT_WITH_SPECIALIST_GAP`: general answer is ready, specialist scope remains undefined.
- `READY_TO_PRESENT_WITH_HOSTED_BLOCKER`: answer is ready but actual hosted evidence is unavailable.
- `NOT_READY`: answer or control evidence is internally inconsistent.
